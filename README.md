ECM TimeTracker

Короткая инструкция по запуску и тестированию расширения в VS Code.

1) Откройте эту папку в VS Code.
2) Откройте панель Run and Debug (Запуск и отладка) → выберите "Launch Extension" (если нет — добавьте конфигурацию для расширения).
3) Нажмите F5 — запустится новая окно VS Code с установленным локально расширением.
4) При открытии проекта расширение запустится автоматически (activationEvents: "*").
5) Статус-бар слева будет показывать `ECM чч:мм:сс` и индикатор простоя `(idle)`.
6) Клик по статус-бару откроет страницу статистики, кнопка "Завершить задачу и сгенерировать отчёт" сохранит запись в историю и откроет отчёт.

Файлы:
- package.json — метаданные расширения и команды
- extension.js — точка входа: регистрация команд и создание трекера
- tracker.js — легковесный модуль трекинга активности и вебвью

Примечание: реализация минимальная и ориентирована на быстрый запуск и доработку. Можно расширить слежение за активностью (события ОС), хранение задач/меток, фильтры по проектам и экспорт отчётов.
